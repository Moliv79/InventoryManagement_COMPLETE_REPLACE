# Inventory Management System

## DBMS Project

This is a web-based Inventory Management System developed as a DBMS project.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Main Features

- Admin Login
- Dashboard
- Product Management
- Category Management
- Supplier Management
- Customer Management
- Purchase Products
- Outgoing Products
- Stock Management
- Orders
- Delivery
- Reports

## Database

The project uses MySQL as the database.

The database file is:

inventory_management.sql

It can be imported into MySQL Workbench to create the database and its data.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required packages:

npm install

4. Make sure MySQL is running.
5. Import `inventory_management.sql` into MySQL.
6. Start the server:

node server.js

7. Open:

http://localhost:3000
